# Compétences Techniques (Hard Skills)

## Programmation et Développement
* **Python** : Niveau avancé. Utilisation quotidienne pour l'analyse de données, le scripting, le développement web et l'IA.
    * *Bibliothèques* : Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn (Machine Learning supervisé/non-supervisé), Plotly (interactif).
    * *Frameworks* : Streamlit (création d'apps data-driven), Flask (conception d'API).
    * *IA* : Utilisation des API OpenAI, gestion des Embeddings et bibliothèques de traitement du langage naturel (NLP).
* **R / RStudio** : Maîtrise du traitement statistique, manipulation via le `tidyverse` (dplyr) et visualisation avancée (ggplot2, Shiny pour apps interactives).
* **SAS** : Programmation SAS Base pour la gestion de données statistiques complexes (Macro-langage, PROC SQL, SAS Guide).
* **Web** : Connaissances fonctionnelles en HTML5, CSS3, PHP et JavaScript pour la mise en forme de reportings web et d'interfaces SI.

## Bases de Données (Data Management)
* **SQL** : Création de requêtes complexes (jointures, agrégations, sous-requêtes, optimisation).
* **SGBD** : PostgreSQL, MySQL, Oracle.
* **Modélisation** : Conception de modèles conceptuels (MCD) et logiques (MLD) avec la méthode Merise (utilisation de Looping).
* **NoSQL** : Notions fondamentales sur MongoDB (gestion de documents JSON).

## Business Intelligence (BI) et Dataviz
* **Power BI** : Création de tableaux de bord interactifs, gestion des modèles de données en étoile, calculs DAX complexes et Power Query (M).
* **Tableau Software** : Visualisation de données avancée, exploration et Data Storytelling.
* **Excel** : Niveau expert (Tableaux croisés dynamiques, Power Pivot, Power Query, macros VBA).

## Statistiques et Mathématiques Appliquées
* **Analyses** : ACP (Analyse en Composantes Principales), AFC, classifications et modélisations.
* **Inférence** : Tests d'hypothèses (Chi-deux, ANOVA, Student), régressions linéaires et logistiques.
* **Mathématiques** : Algèbre linéaire, Probabilités, Analyse et Calcul Matriciel.

## Environnement et Outils
* **Versionning** : Git et GitHub (gestion de branches, commits, pull requests, travail collaboratif).
* **IDE** : Visual Studio Code, PyCharm, Jupyter Notebook, SAS Guide.
* **Système** : Windows, Linux (lignes de commande bash de base, environnements virtuels .venv).
