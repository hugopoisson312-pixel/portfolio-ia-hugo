# Projets Académiques et Réalisations (SAé)

## Projet LLM RAG - Assistant IA Personnel (Projet Actuel)
* **Type** : Projet individuel - Développement IA.
* **Description** : Conception d'un agent conversationnel capable de répondre aux questions sur mon profil professionnel en utilisant mes propres documents comme source de vérité.
* **Architecture & Stack** :
    * Modèle : OpenAI `gpt-4o-mini` via API.
    * Vecteurs : Base de données vectorielle **Upstash Vector** (Embeddings BAAI/bge-m3, Metric COSINE).
    * Frontend : Interface de chat développée avec **Streamlit**.
* **Compétences** : Génie logiciel, NLP, API Rest, gestion de base de données hybride (Dense/Sparse).

## SAé : Analyse Statistique de Données Ouvertes (Open Data)
* **Type** : Projet de groupe (3 personnes).
* **Contexte** : Analyse d'un jeu de données Open Data massif (ex: données SNCF ou Climat).
* **Réalisations** :
    * Nettoyage complet (Cleaning) et traitement des valeurs manquantes/aberrantes avec Pandas.
    * Analyses statistiques exploratoires et tests de significativité (Chi2, ANOVA).
    * Rédaction d'un rapport de synthèse structuré de 30 pages et soutenance orale.
* **Outils** : Python, Jupyter, Excel, R.

## SAé : Création d'une Base de Données Relationnelle SI
* **Contexte** : Modélisation complète du système d'information d'une entreprise de location de voitures.
* **Réalisations** :
    * Conception du MCD (Modèle Conceptuel de Données) respectant les formes normales.
    * Implémentation physique sous PostgreSQL.
    * Développement d'une interface de gestion CRUD en PHP/HTML/CSS.
* **Outils** : Looping (MCD), PostgreSQL, PHP, SQL.

## SAé : Tableau de Bord Décisionnel (Business Intelligence)
* **Contexte** : Aide au pilotage stratégique pour un responsable des ventes.
* **Réalisations** :
    * Importation de données hétérogènes et création d'un modèle de données robuste.
    * Création de mesures calculées et indicateurs clés (KPI) en DAX.
    * Design d'un dashboard interactif facilitant le Drill-down.
* **Outils** : Power BI, Tableau Software.
